# Levels Playbooks

Detailed operating playbooks for each revenue band.

Playbook files:
- level-01-0-5l.md
- level-02-5-20l.md
- level-03-20-50l.md
- level-04-50l-1cr.md
- level-05-1cr-plus.md

Each file will contain:
- What this level feels like
- Key metrics & healthy ranges
- Primary focus (EDGE extraction priorities)
- Creative volume & type recommendations
- Ad spend & testing allocation
- Conversion & store priorities
- Fulfillment & capital notes
- Common traps
- 90-day action checklist

Use these files as the first routing layer after `SYSTEM.md`. Once the founder's revenue level is identified, combine the relevant level playbook with the cross-cutting system files in `/systems/`.
