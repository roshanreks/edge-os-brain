# Raw Client Notes

Store raw or lightly cleaned client/founder inputs here:
- diagnostic calls
- intake forms
- WhatsApp summaries
- brand audits
- store screenshots notes
- performance snapshots

Rules:
- Remove sensitive data before sharing with external tools.
- Keep raw notes separate from final diagnosis.
- Final diagnosis should reference `/systems/diagnostic-engine.md` and the relevant level playbook.

Suggested filename format:

`YYYY-MM-DD-brand-or-category-diagnostic.md`
