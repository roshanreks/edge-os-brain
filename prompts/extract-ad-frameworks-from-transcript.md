# Prompt: Extract Ad Frameworks from Transcript

You are expanding the EDGE OS Brain with practical ad-making knowledge.

I will give you a transcript, article, or notes about paid ads, UGC, founder content, creators, editing, hooks, media buying, or creative testing.

Your job:

1. Summarize the ad thesis in 3-5 sentences.
2. Extract each ad framework or format.
3. Map each format to:
   - awareness stage
   - Level 1-5
   - low-effort or high-effort
   - founder, creator, customer, expert, or celebrity content
   - best funnel destination
4. Extract:
   - hook examples
   - script structure
   - visual shot list
   - editing notes
   - proof elements
   - CTA
   - metrics to judge it
5. Add each useful format to a proposed update for `systems/ad-types-library.md`.
6. Flag contradictions with `systems/creative-engine.md` or current testing volume rules.

Output clean Markdown suitable for `/wiki/` plus a short "Recommended System Updates" section.
