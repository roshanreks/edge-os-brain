- Treat this repository as the single source of truth for EDGE OS.
- Always load `SYSTEM.md` first.
- When expanding knowledge, write new high-quality content into `/wiki/` or the appropriate `/systems/` or `/levels/` file. Never overwrite raw sources in `/raw/`.
- Prefer structured Markdown with clear headings.
- When extracting from YouTube or research, use the prompts in `/prompts/`.
- Maintain the 5-Level structure and EDGE framework as the organizing principles.
- For client/founder advice, route through `systems/diagnostic-engine.md` after loading the relevant Level playbook.
- Keep raw source material in `/raw/`, compiled knowledge in `/wiki/`, and durable operating rules in `/systems/`.
- If two files overlap, preserve both and add links/notes instead of deleting prior work.
