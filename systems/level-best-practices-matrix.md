# Level Best Practices Matrix

This matrix turns EDGE OS into a practical operating checklist by level and department.

Use it after identifying the founder's Level. It should route the advisor to the right system files and stop the founder from copying tactics meant for a different stage.

## Level 1: 0-5 Lacs Monthly

Primary job: prove demand, repeat signal, and first edge.

| Department | Best practices |
|---|---|
| Product | focus on one hero product; talk to customers; fix expectation gaps; avoid SKU sprawl |
| Creative | 8-20 concepts/month; founder videos, raw UGC, demos, review statics, simple problem/solution |
| Landing page/PDP | clear promise, product visual, price, CTA, reviews/testimonials, shipping/COD clarity |
| Copywriting | use customer language; simple pain/promise/proof; do not overcomplicate awareness stages |
| Offer | simple starter offer or bundle; free shipping threshold; clear guarantee/returns |
| Testing | smoke tests, creative tests, customer interviews; no fake statistical A/B tests |
| Product development | improve hero first; small-batch tests only |
| Scale | scale only what shows product and creative signal; watch repeat and refund quality |

## Level 2: 5-20 Lacs Monthly

Primary job: multiply what works and build early systems.

| Department | Best practices |
|---|---|
| Product | protect hero; improve reviews; test simple bundles and adjacent variants |
| Creative | 20-50 concepts/month; create 10+ variants of winning angles; add comparison/objection ads |
| Landing page/PDP | match PDP to winning ads; make reviews clickable; improve image carousel as sales tool |
| Copywriting | build top 3 angle library; write objections and FAQs from real comments/support |
| Offer | test bundles, free gift vs discount, first-purchase vs repeat offers |
| Testing | weekly creative batch; simple CRO tests; monthly customer language mining |
| Product development | require customer evidence before new SKUs; use small batches/preorders |
| Scale | increase spend gradually; protect test budget; install retention flows |

## Level 3: 20-50 Lacs Monthly

Primary job: build repeatable acquisition and expand awareness.

| Department | Best practices |
|---|---|
| Product | build front-end/back-end logic; stage-gate adjacent products; improve hero economics |
| Creative | 50-120 concepts/month; static angle tests; creator routines; problem/solution/unique mechanism |
| Landing page/PDP | build Hero, Quiz, Advertorial, and comparison pages by traffic temperature |
| Copywriting | move beyond Product Aware; write mechanism, comparison, and education copy |
| Offer | starter kit, full bundle, cart cross-sell, post-purchase upsell, replenishment |
| Testing | biweekly CRO sprints; big-swing tests when old pages block scale; read RPU not only CVR |
| Product development | product scorecard before inventory; launch post-mortems |
| Scale | manage RTO, contribution, creative fatigue, and cash before pushing harder |

## Level 4: 50 Lacs-1 Cr Monthly

Primary job: systems, association, retention, portfolio discipline.

| Department | Best practices |
|---|---|
| Product | product roadmap; portfolio roles; launch calendar; supplier and inventory planning |
| Creative | 100-250+ concepts/month; creative pod; high-effort versions of proven winners |
| Landing page/PDP | persona pages, creator pages, offer pages, category education, speed governance |
| Copywriting | full-funnel copy; brand codes; expert/creator proof; category POV |
| Offer | full money model: attraction, upsell, downsell, continuity; cohort-based cross-sells |
| Testing | big-swing + incremental + plus-one tests; surveys, heatmaps, reviews, AI synthesis |
| Product development | launch SOP; forecast; post-mortem; controlled category expansion |
| Scale | use association/PR/creator clusters to open new pools; measure blended contribution |

## Level 5: 1 Cr+ Monthly

Primary job: defend edge, expand distribution, and manage portfolio economics.

| Department | Best practices |
|---|---|
| Product | portfolio strategy; channel-specific assortment; category expansion with stage gates |
| Creative | 200-500+ concepts/month where spend demands it; newsroom ops; brand/performance/retention lanes |
| Landing page/PDP | channel-specific funnels; personalization; AI-assisted page production with human QA |
| Copywriting | category leadership, founder POV, cultural relevance, retention and launch narratives |
| Offer | portfolio money model, membership/loyalty, subscriptions/refills, premium anchors |
| Testing | experimentation council; incrementality; MMM/holdouts where possible; documented knowledge base |
| Product development | formal R&D roadmap; cash/inventory forecasting; kill/scale decisions by contribution |
| Scale | expand distribution across paid, owned, earned, marketplace, offline, PR, partnerships |

## Best Practice Rule

A best practice is only best when it fits:
- level
- awareness stage
- traffic source
- product category
- margin
- cash cycle
- creative capacity
- fulfillment reality

When in doubt, diagnose before prescribing.
