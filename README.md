# EDGE OS Brain

**The complete operating system and knowledge brain for scaling Indian D2C / e-commerce brands.**

This repository is the single source of truth for the EDGE OS framework — a 5-Level revenue roadmap + EDGE extraction system + Eugene Schwartz awareness levels + detailed operating systems for creative, conversion, fulfillment, capital, branding, and more.

## Purpose

- Persistent, version-controlled brain that works across Grok, Claude, GPT, Cursor, and any other model
- Structured so any AI can load the right context and give precise, level-specific advice to brand founders
- Designed for continuous expansion (YouTube transcripts, research, client diagnostics, new insights)

## Core Structure

```
edge-os-brain/
├── SYSTEM.md                 # Master instructions for every model
├── CLAUDE.md                 # Claude-specific guidance
├── AGENTS.md                 # General agent rules
├── INDEX.md                  # Master catalogue
├── core/                     # Immutable foundations
├── levels/                   # Detailed playbooks (0-5L → 1Cr+)
├── systems/                  # Cross-cutting operating systems
├── raw/                      # Immutable source material (transcripts, research)
├── wiki/                     # Compiled high-quality knowledge
└── prompts/                  # Extraction and diagnostic prompts
```

## How to Use

1. Clone or open this repo in Cursor / Claude Code / VS Code
2. Load `SYSTEM.md` + relevant folders into your AI context
3. For Claude Projects: upload key files or link the repo
4. Feed new YouTube videos → put transcripts in `raw/youtube/` → run extraction prompts
